## 图纸口径

采样 BRAM 由 CPU 通过 GP0 读取并复制到 DDR；CNN 通过 AXI 主接口和 HP0 访问 DDR。工程没有独立 AXI DMA / CDMA。CNN 用轮询完成，不画未接入的 CNN 完成中断。

HLS 层间数据按真实源码尺寸标注。权重固化，登记是 5D 与 64D 成对参考的持久化，不是在线神经网络训练。时钟分为 PL AXI 100 MHz 与采样 25.6 MHz；名义采样率为 25.6 k 对/秒。

H02 为功能框图，不是电气连接或强电施工指导。地址与位宽仅在已核对的位置标注；AXI 顶层彩线为语义分组，不是完整逐引脚示意。
