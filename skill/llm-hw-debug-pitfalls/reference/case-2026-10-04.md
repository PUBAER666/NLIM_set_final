# 案例：两个被自己推翻的判据（2026-10-04）

> 本文件是 `SKILL.md` 第四节（判据要在对照组上成立）与第五节（利用数据自带的 null）的**证据来源**。
> 场景：EES-331 上采集手机/平板充电器的交流输入，XADC 重建值与功率计读数比对。
> 现象：部分适配器偏差大（+3.8 ~ +15.7 %），大功率阻性负载几乎为零。
> 与 `case-2026-09-28.md` 的区别：那次错在**模型的推理前提**；这次错在**模型自己造的判据**。

## 二、两个被推翻的判据（**本案例的核心**）

### 判据 A · 「非锁相残差」

```
假设：电流 = 锁相分量 + 残差；残差 = 混进来的干扰
结果：手机充电器残差占总功率 24 %，充电板 34~78 %     ← 看起来像根因
```

**推翻它的不是推理，是一个对照实验：把同一判据用在已知答案的样本上。**

| 样本 | 残差谱（50/150/250/350/450 Hz，mA） | 形态 |
|---|---|---|
| 无载帧（纯噪声，**已知答案 = 无信号**） | 0.8 / 0.8 / 0.8 / 0.8 / 0.8 | **平的** |
| charger3 ★苹果 | 7.4 / 9.9 / 13.0 / 14.8 / 15.3 | 递增 |
| pad1 ★苹果 | 27.2 / 30.3 / 23.6 / 22.2 / 19.8 | 递增 |
| laptop_02 [Windows] | 2.5 / 4.3 / 5.1 / 6.2 / 6.4 | 递增 |
| lamp_01 [LED] | 1.7 / 2.8 / 3.9 / 3.9 / 4.3 | 递增 |

**递增形态在苹果、非苹果、对照组三边同时出现 → 是判据的假象，不是样本的性质。**

**机理**：判据用线性 `f0` 斜坡构造相位参考。电网实际在 49.95~50.15 Hz 漂，
第 n 次谐波累积 n 倍相位误差 → 阶次越高越锁不住 → 残差谱呈递增伪影。

### 判据 B · 「负载功率不稳 → 与功率计读数错开」

```
假设：快充在爬坡，采集窗口与功率计读数不在同一时刻 → 偏差可正可负
证据：charger1 逐 2 s 功率 1.0 → 8.5 → 16.9 → 30.8 → 51.6 → 57.0 W    ← 确实不平
```

**推翻它的是一个反例样本：**

| iPad 记录（两端都平） | 值 |
|---|---|
| 功率计（第 29–58 秒） | 0.184 ~ 0.187 A |
| NILM | 0.2135 ~ 0.2155 A |
| **差值** | **恒定 +15.7 %** |

功率不稳可以**叠加**误差，但解释不了**恒定的偏大**。

## 三、模型主动做的修正（**展示的是正确姿势**）

1. **第 5 步的自检是模型自己想到的**，不是用户要求的。判据刚给出一个"漂亮"的结论，
   模型自己回头去问："这个判据在已知答案的样本上会说什么？"
2. **第 6 步公开撤回上一轮整张表**，并说明撤回理由（形态学证据，不是"再想想觉得不对"）。
3. **第 3 步主动报告了与用户前提相反的结果**：用户说"苹果几乎无偏差"，
   模型实测 iPad 偏差 +15.7 %（三条里最大），并给出为什么用户会形成那个印象的解释
   （笔记本适配器 0.6 A 处只剩 +5 %）。**没有顺着用户的前提说话。**
4. **第 11 步之后主动把「模型测不出的部分」列成表**（重复性、电压 2.4 %），
   而不是把它们混进结论里。

## 四、人做对了什么（**模型做不到的部分**）

| # | 用户动作 | 作用 |
|---|---|---|
| 1 | **纠正品牌标注**：仓库里 `data/raw/` 全部**没有任何品牌元数据**，`charger3` 看起来像"第三只安卓"，实际是苹果 | 模型无法从任何文件推断；按目录名猜必错 |
| 2 | **补采 60 s 数据 + 功率计逐秒读数** | 提供**唯一的外部锚点**。此前所有比较都是模型自说自话 |
| 3 | **补上安卓的功率计读数** | 发现同设备两次采集差 4.9 %，**推翻了模型的"已收敛"错觉** —— 这一步是整轮的转折点 |
| 4 | **确认「RV 没被动过」** | 一刀砍掉整个"增益漂移"分支；并让「电压读数高 2.4 %」这条从"模型没查"升级为"待定案" |

> **#3 是本案例最值钱的一步**：不是模型想到了什么，是**用户补的数据**让模型发现
> 它正要下结论的那个量本身只有 ±3~5 % 的重复性。**模型不会主动怀疑自己刚测出的数。**

## 五、最终成果

| 项 | 结果 |
|---|---|
| 根因 | **被夹住的火线对无屏蔽开合式 CT 的容性耦合**，0~35 mA，与市电同步、与负载无关（初稿判为「Y 电容共模电流」，被夹 L+N 的实测推翻） |
| 为什么"手机偏差大、笔记本偏差小" | 加性 → 相对误差 ∝ 1/I，与品牌无关 |
| 测量链是否可信 | ✅ **是**。同工况重采、扣本底后与功率计差 **−0.5 %** |
| 被推翻的模型结论 | 判据 A（整张表）、判据 B（作为主因）、「苹果 PF 高」假设、品牌标注 |
| 遗留 | 台架重复性 ±3~5 %、电压读数与功率计差 2.4 % |
| 产出 | 分析报告 1 份、复现脚本 1 个、规范文档修正 2 处、本案例 |
