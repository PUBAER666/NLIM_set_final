# 黄金回归协议

## 1. 黄金输入必须固定

不要在 baseline 和 candidate 两边使用不同的数据预处理结果。

推荐保存：
- Sample_ID
- 原始输入文件 hash
- 输入 shape
- 预处理版本

## 2. 比较层次

从强到弱：

1. 文件 hash 完全一致
2. 配置语义一致
3. 中间特征/距离一致
4. 路由状态一致
5. 最终预测一致

## 3. 数值容差

板端、NumPy、PyTorch、定点实现之间可能存在浮点差异。

容差必须：
- 预先声明；
- 按变量类型设置；
- 不能为了“让测试通过”事后无限放宽。

## 4. 失败处理

一旦失败，先定位差异来源：
- 资产变了？
- 预处理变了？
- 类别索引变了？
- 数据排列变了？
- 浮点/定点误差？
- 推理分支逻辑变了？

不要只看最终 Accuracy 是否差不多。
