# 数据用途与来源

golden 中的已知、未知和 iPad 波形来自用户交付的板端模型验证资料，golden_vectors.json 记录参考输出。本次用于测试包内 PS 数值路径、登记匹配和基础已知保护，不用于估算新测试集准确率或训练。

field_logs/20261101_205548 是用户提供的历史现场故障复现，包含事件与状态时间序列。它有研究价值，但不是新版本验收结果；不要统计为新版误识率，也不要据此宣称最新代码现场问题已经全部解决。

大规模训练原始数据没有全部复制进本包。板端推理所需的已导出权重和资产在 src/ps 与 src/hls；本包复现范围为部署工程与数值验证，不包括重新训练所有模型。

公开发布前核查标签、人工登记名称和数据授权。原始模型与采集数据在用户原目录保留，本次未删除。
