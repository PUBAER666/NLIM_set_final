# NLIM_set_final 配套运行包使用说明

固件版本：`NLIM_set_final`。适用于 EES331 / XC7Z020CLG484-1 与现有 V2 PCB。

本版改进开关事件取样、登记匹配及计量恢复，新增单个删除和清空全部登记。已通过本地编译、回归和模拟通信验证。

## 安装

1. 断电后取出 SD 卡，备份卡内文件。
2. 将本包 `sd_card/BOOT.BIN` 替换到 SD 根目录。**不要格式化，不要删除 `NILM430.BIN`、`NILM431.BIN`**，这两个文件保存登记与设置。
3. 插回卡并重新上电。电脑沿用此前已连通的网卡配置；直连板卡默认地址为 `192.168.1.10`。
4. 解压整个包，运行 `check_connection.cmd`，再运行 `start_capture.cmd`。无需安装 Vitis 或 Python。自检中版本应为 `NLIM_set_final`。
5. 页面仍只负责展示和操作；采样、CNN 推理、登记匹配、计量、规则判断均由板端完成。日志生成在本包的 `recordings/时间_编号/` 中。

## 登记和删除

- 保持其他电器状态不变，只操作需要登记的一件电器。等待有效开机或关机事件，输入名称并点击“保存本次样本”。同一电器继续使用相同名称补充样本。
- 等页面提示“已保存到开发板 SD 卡”、SD 显示“已保存”后，再断电。登记可跨重启保留；单类保留最多 12 份代表参考。这是参考库增量登记，不是神经网络权重训练。
- 每个已登记名称旁有“删除”按钮，可删除该电器全部登记样本。底部“清空全部登记”删除所有新增登记。两者均需确认，取消不发送删除指令。
- 删除在 SD 保存成功后生效，断电重启不会恢复。被删名称的名单项同步移除；总功率上限、碳因子、原模型和其他名单不变。网页不会删除电脑已有的采集日志。
- 保存失败时原登记继续生效，页面显示 SD 错误；不要将“正在保存”当作已完成。删除不可用页面撤销，需重新登记或在断电时恢复事先备份的整套 SD 数据。
- 删除期间进行中的事件匹配会取消，正在运行的电器归因可能进入“待确认”，以免旧编号对应到其他电器。随后用独立、稳定的开关事件重新确认。

## 本版变化

1. 首次检测到变化时冻结稳定背景；短暂启动抖动不再不断替换前置波形。后置窗口从变化确认后开始取样。背景不合格单独报告 `BACKGROUND_UNSTABLE`，不继续重算同一坏背景。
2. 原模型判未知后，登记匹配使用登记支持范围及不同登记名称之间的区分度，不再因“原类别参考距离更近”直接拒绝。原模型已知结果仍受保护。最终事件仍要求两个连续检查点、每点三个窗口一致。
3. 计量恢复按四个采样块的平均功率判断，连续七个窗口通过后恢复，最多等待五秒。数据无效、出现新事件或功率不匹配仍会中断或重置；之前未归因电能不补算到某个电器。
4. “识别判断详情”显示前后窗口实测值、稳定门限、最近登记距离、接受门限、登记区分度和具体拒绝原因。待计算窗口不显示上一事件的模型数值。“功率暂未归因”不代表又发现了一个未知电器。

`verify_package.cmd` 可校验包内文件。回退时使用备份的 BOOT 和对应旧接收工具；它们共用 schema 5 登记库，**仅回退 BOOT 不会恢复已经删除的登记**。
